# μTZ workspace

Tiny, embeddable latitude/longitude → IANA timezone lookup for Rust.

The library is the [`utz`](utz/) crate — its [README](utz/README.md) covers
features, preset bundles, and usage. Everything else here exists to build,
measure, or ship the data it reads.

- [Interactive viewer](https://docwilco.github.io/utz/live/) — explore the
  size/accuracy tradeoff on a map
- [API documentation](https://docwilco.github.io/utz/docs/utz/)

## Crates

| crate | role |
|---|---|
| [`utz`](utz/) | the runtime lookup library (lat/lon → IANA tzid) |
| [`utz-common`](utz-common/) | container header types shared by reader and encoder |
| [`utz-encode`](utz-encode/) | container encoder library |
| [`utz-build`](utz-build/) | encoder CLI, measurement commands, and the tuning viewer |
| [`utz-simplify`](utz-simplify/) | boundary-simplification algorithms (native + wasm for the viewer) |
| [`utz-data-*`](utz-data-tiny/) | preset data crates, each shipping one generated `.utz` asset |
| [`utz-bench-common`](utz-bench-common/) | shared lookup-bench harness (`no_std`, used by the firmware) |
| [`utz-bench-cli`](utz-bench-cli/) | host-side lookup bench |
| [`utz-bench-firmware`](utz-bench-firmware/) | embedded lookup bench (own workspace, cross-compiled) |

## Development

One-time setup after cloning — point git at the tracked hooks:

```sh
git config core.hooksPath .githooks
```

The pre-commit hook runs everything CI runs; both call
[`scripts/checks.sh`](scripts/checks.sh), the single source of truth for
formatting, clippy, the test matrix, bare-metal builds, and docs.

Preset `.utz` assets are gitignored and regenerated by
[`scripts/gen-presets.sh`](scripts/gen-presets.sh) (the `presets` check
stage runs it when assets are missing; source downloads are cached in
`cache/`).

`utz/README.md` is generated from the `utz` crate docs by
[`scripts/gen-readme.sh`](scripts/gen-readme.sh) — edit the doc comment in
`utz/src/lib.rs` (or `utz/README.tpl`), not the README; the hook
regenerates it and rejects hand edits.
